CopilotMaster MD-102 – komplett oversiktskart

En enkel totaloversikt over Microsoft endpoint management, bygget for å vise hvordan Intune, Entra ID, sikkerhet, apper, oppdateringer og enhetsadministrasjon henger sammen. Klikk på et område for å se innholdet og de direkte avhengighetene.

MD-102 oversiktskartForstå → kjenn igjen → velg riktig → testFokus: arkitektur, ikke pugging
Avhengigheter: Kun ett nivå vises. Grønt = valgt område. Blått = direkte avhengigheter. Klikker du på et blått område, nullstilles forrige markering og bare det nye områdets direkte avhengigheter vises.

Arbeidsregel: Finn oppgaven i kjeden konfigurere → oppdage → vurdere → håndheve → rette. Finn så korrekt policy, rolle eller handling.
HØY1. Windows Update – komplett oversikt
Update Rings
  • Deferral for quality og feature updates
  • Deadlines, grace period, active hours og restart
  • Brukervarsler og automatisk update behavior
  • Pause og uninstall av feature/quality updates
  • Pilot-, test- og production-ringer
Update Ring styrer klientadferd. Den er ikke førstevalg for å låse enheten til én bestemt feature-versjon.
Feature Update Policy
  • Lås enheter til målversjon, f.eks. Windows 11 24H2
  • Hindrer oppgradering forbi målversjonen
  • Kontrollert utrulling av større OS-versjoner
  • Windows 10 til Windows 11-scenarioer
Quality Update Policy
  • Månedlige kumulative sikkerhets- og kvalitetsoppdateringer
  • Målrettet utrulling av bestemte quality updates
  • Arbeider sammen med Update Rings for restart/deadline/user experience
Expedite Quality Updates
  • Skyv støttet kritisk quality/security update så raskt som mulig
  • Omgår normal deferral og vanlig utrullingstid
  • Endrer ikke fremtidig månedlig update-strategi
Hotpatch
  • Støttede sikkerhetsoppdateringer uten umiddelbar restart
  • Avhenger av støttet Windows-utgave, policy og enhetsstatus
  • Hører under quality update management, ikke feature updates
Driver Update Policy
  • Drivere og firmware fra Windows Update
  • Automatisk eller manuell godkjenning
  • Kontroller maskinvarestabilitet, kompatibilitet og utrulling
  • Restart/user experience styres fortsatt av Windows Update client settings
Windows Autopatch
  • Tjenestestyrt update orchestration
  • Kan administrere update rings og utrullingskadens
  • Ikke legg tilfeldige egne ringer oppå Autopatch-managed devices
  • Forstå forskjellen mellom Intune policy og service-managed orchestration
Delivery Optimization
  • Lokalt peer-to-peer update-innhold
  • HTTP only / ingen peering
  • Peering bak samme NAT / LAN
  • Private group / group-ID-baserte peers
  • Reduser WAN/internett-trafikk
  • Konfigureres via device configuration / Settings Catalog
Windows Update client policy / Settings Catalog
  • Granulære Update CSP-innstillinger
  • Update rings er den generelle Intune-overflaten
  • Settings Catalog brukes når en bestemt setting etterspørres
Rapportering og feilsøking
  • Update status og deployment reports
  • Assignment, group membership og policy status
  • Diagnostic data/telemetry og service connectivity
  • Konflikt med Group Policy/WSUS eller blokkert scan
  • LTSC-begrensninger: feature updates støttes ikke på samme måte
Hurtigvalg: timing/restart → Ring · målversjon → Feature · månedlig patch → Quality · kritisk nå → Expedite · restartfri støttet patch → Hotpatch · driver/firmware → Driver policy · lokal deling → Delivery Optimization · tjenestestyrt → Autopatch.
HØY2. Lokale Windows-roller og administratorrettigheter
Lokale grupper du må kjenne
Lokal gruppeBetydning
AdministratorsFull lokal administrasjon på enheten
UsersStandardbruker uten generell elevation
Remote Desktop UsersRett til RDP der øvrige krav tillater det
Local user group membership i Intune
  • Endpoint Security → Account protection → Local user group membership
  • Add/Update: legg til/fjern valgte medlemmer, behold øvrige medlemmer
  • Replace: erstatt hele medlemslisten med den definerte listen
  • Hvis Update og Replace treffer samme gruppe, vinner Replace
  • Ikke kombiner gammel Restricted Groups-policy og LocalUsersAndGroups-policy på samme enhet
Felle: Replace kan fjerne eksisterende helpdesk-/admin-medlemmer du ikke nevner.
Microsoft Entra Joined Device Local Administrator
  • En Entra-rolle som gir lokal administrator på Entra-joined devices
  • Tenant-bred virkning på Entra-joined devices, ikke granulær per liten device-gruppe
  • Krever relevante Entra-lisenser og korrekt rolleadministrasjon
Hvem blir lokal administrator ved join?
  • Ved vanlig Microsoft Entra join legges brukeren som utfører join normalt til lokal Administrators-gruppe
  • Global Administrator og Microsoft Entra Joined Device Local Administrator-prinsipaler inngår i join-modellen
  • Autopilot kan konfigurere brukeren som Standard eller Administrator
Windows LAPS
  • Administrer lokalt administratorpassord sikkert
  • Roter passord og lagre recovery-data i støttet katalog
  • Skille mellom å styre gruppemedlemskap og å styre passordet til lokal admin
Endpoint Privilege Management
  • Standardbrukere kan få kontrollert elevation for godkjente operasjoner
  • Alternativ til permanente lokale administratorrettigheter
  • Least privilege: elevation ved behov, ikke full lokal admin hele tiden
Hurtigvalg: legg gruppe til lokale admins på utvalgte enheter → Local user group membership · tenant-bred Entra device admin → Entra Joined Device Local Administrator · roter lokalt adminpassord → LAPS · godkjent elevation uten permanent admin → EPM.

Dette er brede Microsoft Entra-roller. De kan ofte utføre oppgaven, men er vanligvis ikke riktig svar når spørsmålet krever least privilege.

Role + Scope groups + Scope tags
  • Role: hva kan administratoren gjøre?
  • Scope groups: hvilke brukere/enheter kan administratoren administrere?
  • Scope tags: hvilke Intune-objekter kan administratoren se og administrere?
  • Flere role assignments gir kumulative rettigheter; ingen vanlig deny som fjerner tillatelser
HØY4. Protect devices – sikkerhetsarkitekturen
Konfigurere → Endpoint Security · Oppdage → Defender for Endpoint · Vurdere → Compliance · Håndheve → Conditional Access · Rette → remediation/remote action
Endpoint Security-policyer
  • Antivirus
  • Firewall
  • Disk encryption / BitLocker
  • Attack Surface Reduction
  • Endpoint Detection and Response
  • Account protection
  • Security baselines
  • App Control for Business
Defender, Compliance og Conditional Access
  • Defender for Endpoint beregner machine risk
  • Compliance vurderer risk, OS, encryption, firewall, AV osv.
  • Conditional Access håndhever tilgang til Exchange, SharePoint og andre ressurser
Vurder enheten = Compliance. Blokker ressurs = Conditional Access.
ASR og sikkerhetskontroller
  • Office child processes
  • Executable content fra e-post/webmail
  • USB/device control
  • Audit før Block når påvirkning er ukjent

HØY11. Brukere, device identity og pålogging
Bruker → Device identity → Management → Compliance/risk → Conditional Access

Det du må skille

  • Primary user, Owner og Enrolled by kan være tre forskjellige brukere.
  • Personlig device beskriver ownership. Guest/external beskriver identiteten.

  • Android: work profile, fully managed, dedicated og Entra Shared Device Mode.

HØY13. MAM uten enrollment og Microsoft Tunnel
Unenrolled/BYOD → App Configuration + App Protection → Tunnel for MAM → on-prem resources
AndroidiOS/iPadOS
Tunnel-klientMicrosoft Defender for EndpointTunnel for MAM SDK i appen
App ProtectionJaJa
Per-App VPNJaJa
Device-wide VPNStøttet i Android MAM-modellenIkke i iOS MAM Tunnel-modellen
Defender-app nødvendigJaNei
Android-handlinger
  • App Configuration policy konfigurerer Defender som Tunnel-klient.
  • App Protection policy legges på appene som skal bruke tunnelen.
  • Edge kan trenge egen App Configuration for identity switching.
  • Ikke velg device compliance eller vanlig device VPN-profile når spørsmålet eksplisitt sier unenrolled MAM.
iOS-handlinger
  • Per-App VPN begrenser Tunnel til målrettede apper.
  • Strict Tunnel Mode blokkerer Edge-trafikk hvis VPN ikke er tilkoblet. Det er ikke det samme som å velge hvilke apper som bruker tunnelen.

Automation

Reporting og drift

  • Alerts for compliance drift, enrollment failures og configuration conflicts.

Remote Help og Security Copilot-agenter
  • Remote Help for sikker fjernstøtte med rolle- og scopekontroll.
  • Security Copilot-agenter i Intune: undersøke trusler, analysere ytelse og vurdere anbefalinger.
MIDDELS15. Oppdateringer for iOS, macOS og Android

FORMAT16. Contoso Case Study – starten av eksamen
Spørsmål → objekt → relevante fakta → requirement → handlingstype → løsning
  1. Les spørsmålet før hele caset på nytt.
  2. Finn user, group, device, app eller policy spørsmålet gjelder.
  3. Hent bare relevante facts i fanene.
  4. Sjekk platform, ownership, join/enrollment, group, policy assignment og lisens.
  5. Klassifiser oppgaven: konfigurere, beskytte, vurdere, håndheve, distribuere, oppdatere eller rette.
  6. Eliminer informasjon som ikke påvirker dette spørsmålet.
Største risiko: prøve å huske hele Contoso-miljøet i stedet for å hente målrettet fakta per spørsmål.
FORMAT17. Tre løsninger: «Does this solution meet the goal?»
Mål → bryt ned krav → vurder aktuell løsning alene → dekker alle krav? → Yes/No
  • Hver løsning eksisterer i sitt eget univers
  • Ikke bruk forrige svar som hint
  • Ikke velg beste av tre dersom hver side spør Yes/No
  • Én manglende nødvendig betingelse gir No
PLAN18. Arbeidsmåten med MeasureUp
  1. Forstå: lær arkitekturen fra kartet.
  2. Kjenn igjen: identifiser hva scenariet egentlig vil oppnå.
  3. Velg riktig: skill mellom nærmeste Microsoft-mekanismer.
  4. Test: bruk Manage and maintain devices og Protect devices.
  5. Ved feil: les MeasureUp-forklaringen, finn hvorfor distraktoren var fristende, og plasser løsningen i riktig arkitektur.
  6. Repetisjon: tren nye formuleringer av modellen, ikke samme fasit.
